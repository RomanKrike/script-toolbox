# Preset Library

Settings → Preset Library подключает локальные и сетевые библиотеки.
Default поставляется с плагином; вставленные копии редактируются локально.
New Library создаёт `library.json` в выбранной папке. Add Library подключает
папку с этим файлом. Подключения сохраняются сразу.

## Файлы библиотеки

Корневой `library.json` содержит только метаданные:

```json
{"schema": 1, "id": "studio", "name": "0+Media"}
```

Примеры путей:

| Путь | Host | Категория |
| --- | --- | --- |
| `All/Utilities/Open Folder.json` | all | Utilities |
| `Maya/Project Pipeline/Leo.json` | maya | Project Pipeline |
| `Houdini/Simulation/Cloth/Normal Push.json` | houdini | Simulation → Cloth |
| `Nuke/Review/Preview.json` | nuke | Review |
| `Blender/Modeling/Cleanup.json` | blender | Modeling |
| `Standalone/Utilities/Start Watch.json` | standalone | Utilities |

Имена папок хостов фиксированы: All, Maya, Houdini, Nuke, Blender, Standalone.
Standalone отображает пресеты из Standalone и All; DCC отображают свои пресеты и All.
Категории допускают произвольную глубину. Файл пресета содержит стабильный
`id`, отображаемый `label` и `root` с обычным Item subtree. Host и категория
определяются путём, а не полями JSON. Каждый Item имеет стабильный строковый ID;
вложенные references в библиотеке запрещены.

JSON можно редактировать, переносить, добавлять и удалять вручную. Сохранять
preset ID и Item ID при обновлении существующих определений обязательно:
references привязаны к ID библиотеки, пресета и параметра, а не к пути файла.
Перемещение не разрывает ссылки. Удаление параметра оставляет видимый broken reference.
Дубликаты preset ID во всей библиотеке запрещены.

Старый `toolbox-source.json` и опубликованные папки `revision-*` не поддерживаются.
Автоматической миграции нет. Создайте новую библиотеку и сохраните пресеты заново
или разместите подготовленные JSON в новой структуре с сохранением стабильных ID.

## Сохранение и вставка

ПКМ по папке или параметру в Existing Parameters → Save Selected as Preset.
Один диалог задаёт библиотеку, название, категорию и host. Категория
`Pipeline/Review` создаёт два вложенных уровня. Сохраняется весь subtree;
references превращаются в локальные определения из закреплённого snapshot.
Broken references блокируют сохранение. Нужны права записи в выбранную папку.

Новый пресет получает новый ID и сохраняется в читаемый файл, например
`Maya/Pipeline/Review/Leo.json`. Совпадающие названия получают суффикс ID;
существующие файлы и остальные пресеты сохраняются. Publisher валидирует
полный набор до записи, сериализует операции lock-файлом и откатывает свои
изменения при ошибке записи. Во время публикации синхронизация откладывается.
Скрытая временная `.publish-*` после аварийного завершения блокирует sync:
проверьте библиотеку и удалите оставшийся временный каталог перед повтором.

После публикации и локальной синхронизации пресет сразу появляется в Presets:
редактор открывает вкладку, очищает фильтр и выделяет новую запись. Пресет другого
host скрывается фильтром текущего приложения; статус показывает выбранный host.
Уже закреплённые definitions в открытом редакторе не заменяются.

Каталог: библиотека → категории → пресет → отдельные controls. Двойной щелчок
или Create References вставляет составной пресет: layout остаётся локальным,
controls становятся references. Layout не обновляется централизованно.
Одиночные controls поддерживают Create Reference. `props.scope` сохраняет связи
скриптов внутри вставленного набора, в том числе после копирования и переименования.

## Синхронизация

Check now сканирует JSON и сравнивает автоматически вычисленный fingerprint.
Sync now создаёт проверенный локальный snapshot и атомарно переключает active pointer.
Ни списка файлов, ни revision, ни SHA-256 в сетевом `library.json` нет.
Контрольные суммы и технические поколения находятся только в локальном кеше.
Перед активацией повторно проверяется содержимое сетевой папки; изменившийся
во время копирования или повреждённый набор не заменяет предыдущую рабочую копию.
Sync не пишет в сетевую папку. При недоступной сети используется локальный кеш.

Runtime definitions закреплены до Apply/Accept, Reload Config или нового открытия
Toolbox. Обычные configs используют schema 21, reference configs — schema 22.
Утилита `tools/publish_preset_source.py` публикует подготовленные JSON из плоской
папки (поля dcc/category) или новой иерархии (пути имеют приоритет).
