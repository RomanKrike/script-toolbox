# Быстрый старт

Ниже описан обычный рабочий процесс Script Toolbox: открыть toolbox, изменить структуру, добавить элемент, назначить ему поведение и вернуться в Runtime.

## 1. Откройте Script Toolbox

Из Python-консоли хоста:

```python
import script_toolbox
script_toolbox.show()
```

Окно Runtime показывает текущую конфигурацию toolbox.

## 2. Откройте Interface Editor

Переключитесь в Interface Editor, чтобы изменить структуру toolbox. Editor работает с той же моделью документа, что и Runtime: интерфейс, который вы собираете, непосредственно рендерится в рабочем toolbox.

## 3. Добавьте структуру

Если нужна группировка или раскладка, начните с контейнера. Доступны:

- Folder типов Collapsible, Simple, Tabs и Radio;
- Row;
- Column.

Контейнеры можно вкладывать друг в друга, собирая компактные панели инструментов.

## 4. Добавьте элемент

Создайте, например, Button, Field, Checkbox, Menu, Label или Icon. Настройте внешний вид и, где применимо, скриптовое `name`.

У каждого элемента есть стабильный внутренний `id`. `name` — символический идентификатор для скриптов, а `label` — только отображаемый текст.

## 5. Добавьте поведение

Интерактивные элементы предоставляют поддерживаемые событийные bindings. В зависимости от типа элемента это могут быть click, double-click, изменение значения или события редактирования.

Назначьте скрипт нужному binding. Поддержка языков зависит от хоста:

| Хост | Языки |
| --- | --- |
| Maya | Python, MEL |
| Nuke | Python |
| Houdini | Python, HScript |

## 6. Проверьте в Runtime

Сохраните конфигурацию и вернитесь в Runtime. Проверьте новый контрол: как внешний вид, так и выполнение скрипта.

## 7. Итерируйте безопасно

Interface Editor поддерживает Undo/Redo, Duplicate, Copy и Paste. При дублировании или переименовании вложенных элементов Script Toolbox переписывает поддерживаемые внутренние ссылки, чтобы скопированные блоки оставались самодостаточными.
