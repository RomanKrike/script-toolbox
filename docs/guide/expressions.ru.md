# Visible, Enabled и выражения

В свойствах каждого параметра раздел **GENERAL** содержит **Visible** и **Enabled**.
По умолчанию оба включены. **Name** — уникальное имя для API и выражений;
**Label** — свободная подпись в интерфейсе.

- **Visible**: выключение скрывает элемент и освобождает место в layout.
- **Enabled**: выключение запрещает взаимодействие, включая запуск кнопок.
- **fx**: переключает свойство на вычисление из выражения. Обычный checkbox
  сохраняется, но недоступен, пока включён fx. Выключение fx возвращает его значение.
- Значение скрытого или отключённого параметра сохраняется; API может обновлять его.
- Скрытая/отключённая группа ограничивает потомков. Ребёнок не отменяет это ограничение.
- Скрытая вкладка убирается вместе со страницей; возвращается в исходную позицию.
- Защита linked presets от редактирования — отдельный механизм.

## Проверка на простом примере

1. Создайте Checkbox с Name `use_custom_path`, включите его.
2. Создайте String с Name `preview_path` и Label «Папка превью».
3. Для Enabled поля включите fx и впишите `use_custom_path`.
4. Нажмите Apply. Выключение checkbox отключит поле без перестройки интерфейса.
5. Для проверки скрытия задайте тот же expression для Visible.

Ссылки на параметры подсвечиваются голубым, ключевые слова — фиолетовым,
строки — зелёным, числа и логические значения — оранжевым. Неизвестные имена
подчёркиваются. Есть автодополнение имён; наведение показывает тип и значение.
Под выражением отображается результат или ошибка. Результат в редакторе относится
к staged-документу редактора; runtime использует активные значения после Apply.

## Язык

Ссылки пишутся без скобок и возвращают **значение**, а не состояние Visible/Enabled.
Поддерживаются скалярные Checkbox, String, Menu, Integer, Float и внутренние toggle-значения.
Векторы, списки, Color и чтение состояния из Python-скрипта здесь не поддерживаются.

```text
use_custom_path
!use_custom_path
mode == "preview"
quality >= 2
mode == "preview" && use_custom_path
mode == "preview" || mode == "render"
if draft then true else quality >= 2
```

Есть `true`, `false`, числа (в том числе отрицательные), строки в двойных кавычках,
`== != > < >= <=`, `&& || !`, скобки и `if … then … else`.
Приоритет: `!`, сравнение, `&&`, `||`; if выбирает один из двух результатов.
Логические операторы и if вычисляют только необходимую ветку.

Для Visible/Enabled результат должен быть bool: строки и числа автоматически не
преобразуются. Сравнения требуют совместимых типов; bool не считается числом.
Ошибки синтаксиса, отсутствующие ссылки и неподходящие типы возвращают сохранённое
обычное значение checkbox; причина доступна также в tooltip runtime-элемента.

Name: латиница, цифры и `_`, первый символ — буква или `_`. Имена чувствительны к
регистру. `if`, `then`, `else`, `true`, `false` запрещены во всех вариантах регистра;
`if_enabled` разрешено. Проверка применяется в модели, импорте и редакторе.
При переименовании и дублировании редактор обновляет ссылки; известные цели
сохраняются по ID. Удаление параметра не привязывает ссылку к новому одноимённому.

Язык не выполняет Python, не вызывает функции, не читает файлы и не меняет значения.
Ограничение: 4096 символов и 256 токенов на выражение.

## API

```python
toolbox.disable("preview_path")
toolbox.enable("preview_path")
toolbox.set_enabled("preview_path", True)
toolbox.set_visible("preview_path", False)
toolbox.set_value("use_custom_path", True)
```

Методы изменения Visible/Enabled принимают имя или ID, сохраняют обычное значение
и **выключают fx** соответствующего свойства, сохраняя текст выражения.
`set_value` пересчитывает зависимые состояния; стандартные value-контролы обновляются
точечно. Изменение состояния UI не запускает action-скрипты.

В JSON свойства находятся в `ui`: `visible`, `enabled`,
`visible_expression_enabled`, `enabled_expression_enabled`,
`visible_expression`, `enabled_expression`. Карты `visible_references` и
`enabled_references` связывают имена токенов с ID; их обслуживает редактор/нормализация.

Вычисляемый Value в этом этапе не добавлен. Конструкция if уже поддерживается
движком, но публичные expression-свойства пока только Visible и Enabled.
