# Элементы

Script Toolbox строит интерфейс из контейнеров, интерактивных действий, контролов значений и презентационных элементов.

## Контейнеры

| Элемент | Назначение |
| --- | --- |
| Collapsible Folder | Группирует контролы в сворачиваемой секции |
| Simple Folder | Группирует контролы без сворачивания |
| Tabs Folder | Разделяет содержимое по вкладкам |
| Radio Folder | Переключает взаимоисключающие секции |
| Row | Располагает дочерние элементы горизонтально |
| Column | Располагает содержимое по колонкам |

## Действия

| Элемент | Назначение |
| --- | --- |
| Button | Запуск действия текстовой кнопкой |
| Toggle Button | Кнопка с состоянием и отдельным toggle-поведением |
| Icon | Запуск действия иконкой |
| Toggle Icon | Иконка с toggle-поведением |

В зависимости от типа интерактивные действия могут предоставлять bindings вроде click или double-click.

## Контролы значений

| Элемент | Назначение |
| --- | --- |
| String | Текстовое значение |
| Integer | Целое числовое значение |
| Float | Число с плавающей точкой |
| Checkbox | Булево состояние |
| Menu | Выбор из заранее заданного набора |
| Color | Значение цвета |
| Field | Текстовое/объектное поле с опциональным режимом списка |

Числовые контролы поддерживают scalar/vector-варианты там, где это применимо, и могут отображать sliders.

## Режим списка Field

Field может работать как список для сценариев вроде коллекций объектов сцены. List mode поддерживает множественное выделение, копирование, выбор объекта в сцене двойным кликом и настраиваемое количество видимых строк.

API для управления коллекциями Field:

```python
get_field_selection(...)
add_to_field(...)
remove_from_field(...)
clear_field(...)
```

Используйте list mode, когда контрол должен представлять изменяемую коллекцию, а не одно текстовое значение.

## Презентационные элементы

| Элемент | Назначение |
| --- | --- |
| Label | Показывает неинтерактивный текст |
| Separator | Добавляет визуальный отступ или разделение |

Такие элементы полезны для пояснений, группировки и улучшения читаемости больших toolbox.

## Event bindings

Каждый интерактивный элемент предоставляет только поддерживаемые его типом события. Среди них могут быть:

- click;
- double-click;
- изменение значения;
- события редактирования.

Поведение хранится в `bindings` каждого элемента отдельно от его визуальных свойств.
