# Добавление библиотеки пресетов

**Версия:** руководство описывает ветку Development (`dev`). В стабильной версии этот интерфейс может ещё отсутствовать.

Библиотеки позволяют хранить пресеты в отдельной локальной или сетевой папке и подключать их на разных рабочих местах. В этом руководстве показано, как подключить готовую библиотеку, создать свою и сохранить первый пресет. Пример — проектная библиотека **BEARS**.

Скриншоты сняты с настоящих окон standalone из `dev`, коммит `43ea104`. В Windows и внутри DCC оформление окон может отличаться. Сетевой путь на скриншоте — пример; замените его своим.

## 1. Откройте настройки библиотек

В главном окне выберите **Settings → Open Settings**, затем **Preset Library** в списке слева.

![Настройки Preset Library с кнопками Add Library и New Library](../assets/images/preset-library/settings.png)

Выберите действие в зависимости от того, есть ли готовая библиотека:

| Кнопка | Когда использовать |
| --- | --- |
| **Add Library** | Подключить папку, в корне которой уже есть `library.json`. |
| **New Library** | Создать библиотеку в пустой папке. ScriptToolbox создаст `library.json` и подключит библиотеку автоматически. |

**Default** поставляется с плагином. Для своей библиотеки создайте или подключите отдельную папку.

## 2. Подключите готовую библиотеку

Если руководитель или коллега передал путь к библиотеке, нажмите **Add Library**.

![Диалог подключения библиотеки BEARS с сетевым путём и настройками обновления](../assets/images/preset-library/add-library.png)

Заполните поля:

| Поле | Что указать |
| --- | --- |
| **Name** | Понятное название, например `BEARS`. Пустое поле означает использование названия из `library.json`. |
| **Folder** | Корневую папку библиотеки. Выбирайте её через **Browse…**, а не отдельный файл пресета. |
| **Enabled** | Оставьте включённым, чтобы библиотека отображалась в каталоге. |
| **Updates** | Режим проверки обновлений из таблицы ниже. |
| **Check interval** | Интервал в минутах для режима **Periodically**. |

Например, корневая папка может находиться по адресу `\\studio\tools\ScriptToolbox\BEARS`. Внутри неё должен лежать `library.json`.

### Выберите режим обновлений

| Режим | Поведение |
| --- | --- |
| **Manual** | Обновление вручную через **Check now** и **Sync now**. |
| **On application start** | Проверка и синхронизация при запуске приложения. |
| **Periodically** | Проверка и синхронизация с заданным интервалом. |

Нажмите **Save** в диалоге подключения и дождитесь завершения синхронизации. При добавлении библиотека автоматически копируется в локальный кеш; отдельное нажатие **Sync now** обычно не требуется.

Подключение сохраняется сразу. После успешной синхронизации закройте настройки и откройте редактор заново.

## 3. Создайте свою библиотеку

Если готовой библиотеки ещё нет:

1. В **Preset Library** нажмите **New Library**.
2. Выберите пустую папку на компьютере или в общем сетевом расположении.
3. Введите название, например `BEARS`.
4. Дождитесь создания и синхронизации. Библиотека подключается автоматически.

Если в папке уже есть `library.json`, используйте **Add Library**.

### Сохраните первый пресет

1. Откройте **Editor → Open Editor**.
2. В **Existing Parameters** выберите параметр или папку с набором параметров.
3. Нажмите ПКМ → **Save Selected as Preset**.

![Сохранение Shot Selector в библиотеку BEARS с категорией Pipeline/Review и хостом maya](../assets/images/preset-library/save-preset.png)

| Поле | Пример и назначение |
| --- | --- |
| **Library** | `BEARS` — библиотека, в которую сохраняется пресет. |
| **Preset name** | `Shot Selector` — название в каталоге. |
| **Category** | `Pipeline/Review` — вложенные категории, разделённые косой чертой. |
| **Host** | `maya` — приложение, для которого предназначен пресет. |

Нажмите **Save**. ScriptToolbox сохранит пресет и обновит каталог. Для сохранения нужны права записи в выбранную папку.

В примере создаётся файл `Maya/Pipeline/Review/Shot Selector.json`. Папки хоста и категории создаются при сохранении; `library.json` остаётся в корне.

### Выберите подходящий Host

| Host | Где виден пресет |
| --- | --- |
| `all` | Во всех поддерживаемых хостах, включая standalone. |
| `maya` | В Maya. |
| `nuke` | В Nuke. |
| `houdini` | В Houdini. |
| `blender` | В хосте Blender, если он доступен в вашей сборке. |
| `standalone` | В отдельном приложении ScriptToolbox. |

Если сохранить пресет с `Host = maya` из standalone, он не появится в каталоге standalone. Откройте Maya или сохраните пресет для `standalone` либо `all`, если его скрипты подходят этим хостам.

## 4. Используйте пресет

Откройте **Editor → Open Editor**, затем **Create Parameters → Presets**. Разверните библиотеку и категорию.

![Библиотека BEARS в каталоге Presets рядом с Existing Parameters](../assets/images/preset-library/catalog.png)

На скриншоте показан отдельный тестовый пресет **BEARS → Pipeline → Shot Selector** с `Host = all`.

1. Выберите место вставки в **Existing Parameters**.
2. Дважды щёлкните нужный пресет в каталоге.
3. Нажмите **Apply** или **Accept**, чтобы применить изменения.

Пресеты пользовательских библиотек вставляются как **references**: определения параметров берутся из библиотеки. У составного пресета раскладка остаётся локальной. Для независимого редактирования связанного параметра используйте ПКМ → **Convert to Local Copy**.

## 5. Получите обновления библиотеки

В **Settings → Open Settings → Preset Library** выберите библиотеку.

- **Check now** проверяет наличие изменений.
- **Sync now** загружает актуальную копию в локальный кеш.
- **Edit** меняет путь, название и режим обновлений.
- **Remove** удаляет подключение из этого приложения; файлы общей библиотеки остаются на месте.

Обновлённые определения применяются при следующем открытии Toolbox, через **Reload Config** или **Apply** в редакторе. Синхронизация не заменяет определения уже работающего интерфейса немедленно.

Если сеть недоступна, используется последняя рабочая локальная копия. Для первого подключения нужна доступная папка библиотеки.

## Если что-то не получилось

| Проблема | Что проверить |
| --- | --- |
| Библиотека уже подключена | Выберите её в списке и нажмите **Edit**. Повторное подключение той же библиотеки не требуется. |
| Папка не принимается | В корне должен быть `library.json`. Пустую библиотеку создавайте через **New Library**. |
| Пресет не виден | Проверьте **Enabled**, завершение синхронизации и **Host**. Очистите фильтр в **Presets** и откройте редактор заново. |
| Не удаётся сохранить пресет | Проверьте права записи в библиотеку и доступ к папке. |
| Изменения не появились в Toolbox | После синхронизации используйте **Apply**, **Reload Config** или откройте Toolbox заново. |

Подробности формата файлов и синхронизации: [Preset Library на GitHub](https://github.com/RomanKrike/script-toolbox/blob/dev/docs/PRESET_LIBRARY.ru.md).
