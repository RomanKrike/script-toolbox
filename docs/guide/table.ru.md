# Table / Spreadsheet

Table — таблица с обычными контролами Item в ячейках. Каждый дочерний Item задаёт один столбец: тип и настройки одинаковы для всех его строк. В Existing Parameters отображается **Table → items столбцов**, без отдельных узлов строк и ячеек.

![Таблица с контролами разных типов](../assets/images/table/runtime.png)

## Создание таблицы

1. Добавьте **Table** через Create Parameters → Items → Layout.
2. Выберите Table в Existing Parameters и добавьте дочерние String, Integer, Float, Checkbox, Menu, Color, Button, Label или Icon. Поддерживается перетаскивание.
3. **Label** дочернего item становится заголовком столбца. В его обычном инспекторе задаются значения по умолчанию, диапазон, варианты меню, поля цвета и события. Fixed Width задаёт ширину столбца; остальные столбцы можно растягивать мышью.
4. Выберите Table, задайте **Initial rows** и нажмите **Edit initial rows…** для заполнения начальных данных. Диалог работает с копией: Cancel отменяет изменения, пользовательские скрипты в нём не выполняются.
5. Нажмите Apply или Accept. В основном окне можно редактировать ячейки, добавлять и удалять строки. Данные сохраняются в конфиге.

![Table и столбцы в редакторе](../assets/images/table/editor.png)

Настройки Table: высота строки и таблицы, номера строк, разрешение добавления и удаления строк. Выражения Visible/Enabled дочернего item применяются ко всему столбцу. Контейнеры, Field, toggles, Text и Image пока не являются типами столбцов. Сортировка, фильтрация и формулы ячеек в первую реализацию не входят.

## API

```python
sheet = toolbox.item("shots").table()
row_id = sheet.add_row({"shot": "sh001", "frames": 120, "render": True})
sheet.set_cell(row_id, "frames", 144)
frames = sheet.get_cell(row_id, "frames")
row_data = sheet.row(row_id)
all_rows = sheet.rows
column_names = sheet.columns
sheet.remove_row(row_id)
```

Строка указывается стабильным ID или индексом с нуля. Столбец — именем item, ID или индексом с нуля. Типы и числовые диапазоны проверяются до записи. Изменения используют общий механизм Item и сохранения; обновляется таблица, а редактор изменяемой ячейки остаётся на месте.

События столбца выполняются для конкретной ячейки. Помимо обычных `toolbox`, `item`, `value`, `old_value` и `event`, скрипт получает:

| Переменная | Значение |
| --- | --- |
| `table` | Объект API таблицы |
| `row` | Копия значений строки с ключами по именам items столбцов |
| `row_id` | Стабильный ID строки |
| `row_index` | Текущий индекс строки с нуля |
| `column` | Имя item столбца |

Например, Button может прочитать `row["shot"]` и открыть папку этого шота. Для изменения другой ячейки используйте `table.set_cell(row_id, "status", "Ready")`. Ячейки не являются отдельными items документа: данные строк меняются через API таблицы, определения столбцов — через обычный Item API.

ID столбцов сохраняют связь с данными при перестановке и переименовании. Duplicate/Copy/Paste создаёт новые ID столбцов и строк и переносит данные. Удаление столбца удаляет его значения; Undo в редакторе их возвращает. Заголовки, фон и встроенные контролы используют общую палитру темы.

Текущий рендерер с виджетами допускает до 1000 строк, 64 столбцов и 10 000 ячеек на таблицу. Конфиг использует текущую универсальную схему Item; для открытия нужна сборка с поддержкой Table.
