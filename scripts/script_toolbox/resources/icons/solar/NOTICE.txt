Solar Icons attribution
=======================

This directory contains selected SVG icons from the Solar collection distributed through Iconify.

Iconify:
https://iconify.design/

Iconify Solar collection dataset:
https://github.com/iconify/icon-sets/blob/master/json/solar.json

Solar Icons Set by 480 Design:
https://www.figma.com/community/file/1166831539721848736

License: Creative Commons Attribution 4.0 (CC BY 4.0)
https://creativecommons.org/licenses/by/4.0/

For ScriptToolbox's dark UI, the monochrome Linear SVG variants are stored locally with #d9d9d9 as their stroke/fill color. Geometry is sourced from the Iconify Solar collection; only the display color is normalized for the plugin UI.
