# Iconify Solar assets

The Solar SVG assets used by ScriptToolbox are sourced from the **Solar** collection on Iconify (`solar` prefix), created by 480 Design and licensed under **CC BY 4.0**.

For ScriptToolbox's dark UI, monochrome Linear variants are stored locally with `#d9d9d9` as the SVG stroke/fill color.

Source collection: `iconify/icon-sets` → `json/solar.json`.
